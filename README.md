# emotion_detection_model
xiamen year 1 python assignment

								Image Emotion Detector

DESCRIPTION

A program that uses machine learning to analyze and detect emotions in uploaded images. This program operates by a pre-trained model with end-to-end open-source machine learning platform – TensorFlow to provide users with insights into the emotional content of their images.



KEY FEATURES

1） User Friendly Interface
This application provides a easy and straightforward interface, allowing users to upload and analyze images without hassle.

2） Versatile Image Emotion Recognition 
The underlying pre-trained model ensure quick and precise emotion detection and offering various emotion recognition.

3） Instant Feedback : 
User can review the model’s recognition and provide feedback on the accuracy of the prediction. 
This interactive feature helps ameliorate the model over time.




USER MANUAL

1) Login Screen

- Upon launching the program, the login screen will be displayed.
- Users are required to input their username in order to proceed to the Main Program Screen.
- If no username is provided, an error wndow will appear, prompting the user to enter a username.


2) Main Program Screen

- User can upload image by clicking the "Select" button.
- After uploading an image, initiate the analysis by clicking the "Detect" button.
- The program will start analyzing the emotion of the uploaded image.
- The predicted emotion will be displayed on the screen.
- A Feedback Window will pop up, allowing the user to provide feedback on the accuracy of the model's prediction.
- If the prediction is inaccurate, the user can select the correct emotion from the provided options to help the learning model to improve its accuracy over time.




GETTING STARTED

1) Clone two repository (FinalTkinter.py & FinalDomain.py ) and a zip file (BaseData.zip) to your local machine.
2) Install the required dependencies from Jupyter Notebook as specified in this documentation
3) Open project : “main.py” to modify its path according to your local machine.
4) Launch the program and you should see the login screen.
